Level 1

🐍Python in 10 minutes

CircuitPython is Python made for tiny boards. If you already know Python, skim this and move on. If not, these are the only ideas you need for the whole quest. You'll try them for real once the CLUE is set up.

1. Comments: notes for humans

Anything after # is ignored by the computer.

# This is a comment. The CLUE skips it.

2. print(): talk to the computer screen

print("Hello!")
print(2 + 3)      # prints 5

3. Variables: labeled boxes

score = 0          # a number
name = "Robo"      # text (a "string") goes in quotes
score = score + 10 # now score is 10
print(name, "has", score, "points")

4. True / False and if

Indentation matters! The lines pushed in by 4 spaces belong to the if.

temperature = 30
if temperature > 25:
    print("Hot!")
elif temperature > 15:
    print("Nice.")
else:
    print("Brrr!")

Comparisons: > bigger, < smaller, == equal (two equals signs!), != not equal.

5. Loops: do it again

for i in range(3):   # runs 3 times: i = 0, 1, 2
    print("Hip hip hooray", i)

while True:          # runs FOREVER
    print("I never stop!")

Almost every CLUE program has a while True: loop, so it keeps checking the buttons and sensors forever.

6. Lists and tuples: many things in one box

colors = ["red", "green", "blue"]   # a list
print(colors[0])                     # "red" (counting starts at 0!)
purple = (255, 0, 255)               # a tuple: red, green, blue amounts
x, y, z = (1, 2, 3)                  # "unpack" a tuple into 3 variables

7. import and time.sleep()

import time          # borrow Python's clock tools
time.sleep(0.5)      # wait half a second

from adafruit_clue import clue   # borrow ALL the CLUE powers

8. Functions: your own commands

def cheer(name):
    print("Go", name, "go!")

cheer("Robo")   # Go Robo go!

9. f-strings: mix text and numbers

temp = 21.5678
print(f"Temp: {temp:.1f} C")   # Temp: 21.6 C  (.1f = 1 decimal place)
🧠 Remember
Python is picky: capital letters matter (True not true), colons go at the end of if/for/while/def lines, and indent with 4 spaces.
Level 2

🛠️Setup: power up your CLUE

We only have to do this once. There are 3 parts: (A) install CircuitPython, (B) add the libraries, (C) connect the code editor.

Part A: Install CircuitPython

  1. Go to circuitpython.org/board/clue_nrf52840_express and download the latest stable .UF2 file (not an "Absolute Newest" or beta one).
  2. Plug the CLUE into your computer with your data USB cable.
  3. Double-click the little Reset button (quick: click-click!). The NeoPixel turns green and a new drive called CLUEBOOT appears on your computer.
  4. Drag the .UF2 file onto CLUEBOOT. The light flashes, CLUEBOOT disappears, and a new drive called CIRCUITPY shows up. 🎉
😬 No CLUEBOOT drive?
① Try a different USB cable, since it's probably a charge-only cable. ② Double-click faster (or slower!). ③ Try another USB port. If you see CIRCUITPY instead, CircuitPython is already installed, so skip to Part B.

Look inside CIRCUITPY. You'll see code.py (your program), a lib folder (for libraries) and boot_out.txt. Open boot_out.txt: the first line tells you your CircuitPython version, for example Adafruit CircuitPython 10.0.0. Remember that first number!

Part B: Add the libraries

A library is code someone else wrote that you can borrow. The adafruit_clue library gives us easy commands like clue.temperature. It needs some helper libraries too.

  1. Go to circuitpython.org/libraries and download the Bundle for Version X.x that matches the number from boot_out.txt.
  2. Unzip it. Open the lib folder inside the bundle. It's huge, but we only need a few things.
  3. Copy these into the lib folder on CIRCUITPY (some are folders, some are files ending in .mpy):
Copy thisIt powers…
adafruit_clue.mpyThe easy CLUE commands ⭐
adafruit_apds9960 📁Proximity, gesture & color sensor
adafruit_bmp280.mpyAir pressure & altitude
adafruit_sht31d.mpyHumidity (and temperature)
adafruit_lsm6ds 📁Accelerometer & gyro
adafruit_lis3mdl.mpyMagnetometer
adafruit_display_text 📁Words on the screen
neopixel.mpyThe color LED
adafruit_bus_device 📁Helper that talks to sensors
adafruit_register 📁Another sensor helper
💡 Error says ImportError: no module named '…'?
That means a library is missing. Find the name it says in the bundle's lib folder and copy it over too.
🧑‍🏫 For teachers: the faster way with circup

If Python 3 is installed on the computer, circup installs a library and all its helpers automatically, matched to the board's version. With the CLUE plugged in:

pip install circup
circup install adafruit_clue

Handy for setting up a whole class set of boards.

Part C: Connect to the code editor

  1. Open code.circuitpython.org in Chrome or Edge.
  2. A box pops up asking how to connect. Click USB.
  3. Step 1: click Connect to Device. Chrome shows a list: pick CLUE nRF52840 Express - CircuitPython CDC control (COM…) and click Connect.
  4. Step 2: click Select New Folder, choose the CIRCUITPY drive and click Select Folder. Chrome asks "Allow this site to edit files?": click Allow, then click OK.
  5. A Device Info box shows your board and version. If it says "Update available … alpha", ignore it (alpha = unfinished test version) and click Close.
  6. The editor starts with an empty [New Document]. Click Open and double-click code.py. This is the file the CLUE runs automatically.
  7. Click Serial (bottom left) to open the console on the right. This is where print() messages show up. It has buttons for Halt (stop your program), Restart, Clear and Plotter (live graphs!).
🪄 The golden rule
Edit code.py → click Save + Run → the CLUE restarts and runs your code instantly. That's it!

Your first program

Delete everything in code.py, type this in, and click Save + Run:

from adafruit_clue import clue

print("Hello from my CLUE!")
print("It is", clue.temperature, "degrees C in here")

Look in the Serial console. Did it print the temperature? You just read a sensor! 🎉

🐞 Troubleshooting & the REPL
  • Red error text? Read the last line and look at the line number. Most bugs are typos, a missing :, or wrong indentation.
  • Errors also show on the CLUE's screen, which is handy!
  • REPL = a live Python playground. Click the Halt button (or click in the Serial console and press Ctrl + C), then press any key. You get a >>> prompt. Type 2 + 2 and press Enter! Try the Python lessons above here. Press Ctrl + D to go back to running code.py.
  • Editor can't see the board? Unplug, plug back in, refresh the page, and connect again.
  • The editor also supports Bluetooth for the CLUE, but USB is the easiest way to start.

Mission 1

📺Hello, Screen!

+100 XP

Let's put words on the display. simple_text_display gives you a title plus lines numbered 0, 1, 2…

from adafruit_clue import clue

screen = clue.simple_text_display(title="CLUE QUEST", text_scale=2,
                                  colors=((255, 0, 255), (0, 255, 255), (255, 255, 0)))

screen[0].text = "Hello, world!"
screen[1].text = "My name is"
screen[2].text = "Sam"
screen.show()          # nothing appears until you call show()!

while True:            # keep the program running so the text stays up
    pass               # "pass" means "do nothing"

Colors are (red, green, blue), each from 0 to 255. (255, 0, 255) = full red + full blue = magenta.

🤔 Why the while True?
When a program ends, the CLUE shows "Code done running" and your text vanishes. The endless loop keeps it on screen.
⭐ Bonus: GIANT text anywhere on the screen

For full control, use displayio (the screen's drawing system) and a Label:

import displayio
import terminalio
from adafruit_display_text import label
from adafruit_clue import clue

group = displayio.Group()                 # a "layer" to draw on

# background: a 240x240 bitmap filled with one color
bg = displayio.Bitmap(240, 240, 1)
palette = displayio.Palette(1)
palette[0] = 0x220044                     # dark purple (hex color)
group.append(displayio.TileGrid(bg, pixel_shader=palette))

big = label.Label(terminalio.FONT, text="WOW", color=0x22D3EE, scale=6, x=65, y=120)
group.append(big)

clue.display.root_group = group           # show our layer

while True:
    pass

x and y are pixel positions: (0, 0) is the top-left corner, (239, 239) the bottom-right.

Mission 2

🌈Light Show

+100 XP

The CLUE has three kinds of lights: the NeoPixel (any color), the red LED (on/off) and two white LEDs (on/off, super bright).

import time
from adafruit_clue import clue

clue.pixel.brightness = 0.2    # 0.0 = off, 1.0 = BLINDING

rainbow = [(255, 0, 0), (255, 128, 0), (255, 255, 0),
           (0, 255, 0), (0, 0, 255), (128, 0, 255)]

while True:
    for color in rainbow:
        clue.pixel.fill(color)   # set the NeoPixel color
        clue.red_led = True      # red LED on
        time.sleep(0.3)
        clue.red_led = False     # red LED off
        time.sleep(0.1)

And the white LEDs are one line:

from adafruit_clue import clue

clue.white_leds = True    # flashlight ON (False turns it off)

while True:
    pass
😎 Careful
Don't stare into the white LEDs, they're really bright!
🏆 Challenge
Make a police siren: flash red and blue on the NeoPixel, and blink the white LEDs every time it turns blue.
Mission 3

🅰️Button Mash

+100 XP

clue.button_a is True while A is held down, False otherwise. Same for B.

from adafruit_clue import clue

while True:
    if clue.button_a and clue.button_b:
        clue.pixel.fill((0, 255, 0))      # both = green
    elif clue.button_a:
        clue.pixel.fill((255, 0, 0))      # A = red
    elif clue.button_b:
        clue.pixel.fill((0, 0, 255))      # B = blue
    else:
        clue.pixel.fill((0, 0, 0))        # nothing = off

Counting presses

If we just did count = count + 1 while A is held, it would count hundreds of times per press! Instead we remember whether the button was already down, and only count the moment it goes down.

from adafruit_clue import clue

screen = clue.simple_text_display(title="Clicker", text_scale=3)
count = 0
was_down = False

while True:
    down = clue.button_a
    if down and not was_down:     # it JUST got pressed
        count = count + 1
    was_down = down

    if clue.button_b:             # B resets
        count = 0

    screen[0].text = str(count)   # str() turns a number into text
    screen.show()
🏆 Challenge
Make B toggle the white LED flashlight on and off (hint: use the same "just pressed" trick and clue.white_leds = not clue.white_leds).
Mission 4

🎵Beep Boop Band

+100 XP

clue.play_tone(frequency, seconds) plays a note. A higher frequency means a higher pitch. 262 is middle C.

import time
from adafruit_clue import clue

C, D, E, F, G, A = 262, 294, 330, 349, 392, 440

# Twinkle Twinkle Little Star: (note, how long)
song = [(C, 0.4), (C, 0.4), (G, 0.4), (G, 0.4), (A, 0.4), (A, 0.4), (G, 0.8),
        (F, 0.4), (F, 0.4), (E, 0.4), (E, 0.4), (D, 0.4), (D, 0.4), (C, 0.8)]

for note, length in song:     # unpack each (note, length) pair
    clue.play_tone(note, length)
    time.sleep(0.05)          # tiny gap between notes

There's also clue.start_tone(freq) and clue.stop_tone() for notes that last as long as you want. You'll use those next mission.

Play a happy "level up" sound when A is pressed (notes going UP) and a sad "game over" sound when B is pressed (notes going DOWN).
Mission 5

🎹Touch Piano

+100 XP

The gold pads labeled 0, 1 and 2 on the bottom edge are touch sensors. Your body carries a tiny electric charge, and the CLUE can feel it!

from adafruit_clue import clue

clue.pixel.brightness = 0.2

while True:
    if clue.touch_0:
        clue.start_tone(262)          # C
        clue.pixel.fill((255, 0, 0))
    elif clue.touch_1:
        clue.start_tone(330)          # E
        clue.pixel.fill((0, 255, 0))
    elif clue.touch_2:
        clue.start_tone(392)          # G
        clue.pixel.fill((0, 0, 255))
    else:
        clue.stop_tone()
        clue.pixel.fill((0, 0, 0))
🍌 Fun hack
Clip an alligator clip from a pad to a banana, apple or foil. Now the fruit is a piano key! (Only use fruit and clips, nothing plugged into the wall.)
🏆 Challenge
Add two more notes using button A and button B, so you have a 5-note piano.
Mission 6

🎱Shake & Tilt

+150 XP

The accelerometer measures pushes and pulls, including gravity! clue.acceleration gives 3 numbers (x, y, z). Lying flat and face up, z is about -9.8: that's gravity pulling down. Flip it over and it becomes +9.8!

import time
from adafruit_clue import clue

while True:
    x, y, z = clue.acceleration
    print(f"x={x:.1f}  y={y:.1f}  z={z:.1f}")
    time.sleep(0.2)

Tilt the board and watch the numbers change. Tip it left and right: that's x. Tip it forward and back: that's y.

📈 Graph it!
If you print numbers inside parentheses like print((x, y, z)), the code editor's Plotter can draw them as live lines.

Magic 8-Ball

clue.shake() is True when you shake the board. Raise the shake_threshold number if it triggers too easily, or lower it if you have to shake too hard.

import random
from adafruit_clue import clue

answers = ["Yes!", "No way", "Maybe...", "Ask again", "Definitely", "Nope"]
screen = clue.simple_text_display(title="Magic 8-Ball", text_scale=3)
screen[1].text = "Shake me!"
screen.show()

while True:
    if clue.shake(shake_threshold=20):
        screen[1].text = random.choice(answers)
        screen.show()
        clue.play_tone(880, 0.1)

Build a "spirit level": turn the NeoPixel green when the board is flat (x and y both between -1 and 1), and red when it's tilted.
Mission 7

🌀Spin Detector

+100 XP

The gyroscope measures how fast the board is spinning, in degrees per second. Sitting still, it reads close to 0.

from adafruit_clue import clue

screen = clue.simple_text_display(title="Spin-o-meter", text_scale=2)

while True:
    x, y, z = clue.gyro
    screen[0].text = f"x: {x:6.0f}"
    screen[1].text = f"y: {y:6.0f}"
    screen[2].text = f"z: {z:6.0f}"
    if abs(z) > 200:              # abs() ignores the minus sign
        screen[4].text = "WHEEE!"
    else:
        screen[4].text = ""
    screen.show()

Lay the CLUE flat on the table and spin it like a record. That's the z axis!

🏆 Challenge
Play a higher note the faster you spin (hint: clue.start_tone(200 + int(abs(z)))).
Mission 8

🧭Magnet Hunter & Compass

+150 XP

The magnetometer senses magnetic fields (in microteslas). Earth is a giant magnet, and a fridge magnet is a tiny one.

import math
from adafruit_clue import clue

screen = clue.simple_text_display(title="Magnet Hunter", text_scale=2)

while True:
    x, y, z = clue.magnetic
    strength = math.sqrt(x*x + y*y + z*z)    # total magnet power
    screen[0].text = f"Power: {strength:.0f}"
    if strength > 150:
        screen[2].text = "MAGNET NEARBY!"
        clue.pixel.fill((255, 0, 0))
    else:
        screen[2].text = ""
        clue.pixel.fill((0, 0, 0))
    screen.show()

Bring a magnet close and watch the power jump. Earth's field alone is usually around 25 to 65.

Rough compass

With the board lying flat, the x and y readings point towards magnetic north. atan2 turns them into an angle.

import math
from adafruit_clue import clue

screen = clue.simple_text_display(title="Compass", text_scale=3)

while True:
    x, y, z = clue.magnetic
    heading = math.degrees(math.atan2(y, x)) % 360
    screen[1].text = f"{heading:.0f} deg"
    screen.show()
🔧 Real-world alert
Every magnetometer is a little bit off, and metal or electronics nearby confuse it. If your compass is wonky, that's normal! Real engineers calibrate: slowly turn the board all the way around, note the smallest and biggest x and y, then subtract the middle value ((min + max) / 2) from each reading.
🏆 Challenge
Show "N", "E", "S" or "W" instead of a number.
Mission 9

✋Jedi Hand Powers

+150 XP

The little black sensor at the top of the board shines invisible infrared light and watches it bounce back. That gives us proximity (0 = far, 255 = touching) and gestures (hand swipes!).

Proximity theremin

from adafruit_clue import clue

while True:
    p = clue.proximity
    if p > 10:
        clue.start_tone(200 + p * 5)   # closer hand = higher note
    else:
        clue.stop_tone()

Swipe detector

clue.gesture gives 0 = nothing, 1 = up, 2 = down, 3 = left, 4 = right. Wave your hand about 5 to 10 cm above the sensor.

from adafruit_clue import clue

names = ["", "UP", "DOWN", "LEFT", "RIGHT"]
screen = clue.simple_text_display(title="Swipe!", text_scale=4)

while True:
    g = clue.gesture
    if g != 0:
        screen[1].text = names[g]    # use the number to pick from the list
        screen.show()

Mission 10

🎨Color Copycat

+150 XP

The same sensor can see color! clue.color gives 4 numbers: red, green, blue, clear (clear = total brightness). Turn on the white LEDs so it can see better.

import time
from adafruit_clue import clue

clue.white_leds = True
clue.pixel.brightness = 0.3
screen = clue.simple_text_display(title="Color Copycat", text_scale=2)

while True:
    r, g, b, c = clue.color
    screen[0].text = f"R {r}"
    screen[1].text = f"G {g}"
    screen[2].text = f"B {b}"
    screen.show()

    biggest = max(r, g, b, 1)            # the 1 stops us dividing by zero
    # scale so the strongest color becomes 255
    clue.pixel.fill((r * 255 // biggest, g * 255 // biggest, b * 255 // biggest))
    time.sleep(0.1)

Hold a colorful LEGO brick, sticky note or marker cap right on top of the sensor. The NeoPixel copies it!

Mission 11

⛅Weather Station

+150 XP

Four air sensors in one program:

  • clue.temperature: degrees Celsius
  • clue.humidity: % of water in the air
  • clue.pressure: air pressure in hPa (falling pressure often means rain is coming!)
  • clue.altitude: height in meters, worked out from pressure
import time
from adafruit_clue import clue

# Look up today's sea-level pressure for your town on a weather site
# and put it here to make altitude more accurate.
clue.sea_level_pressure = 1013.25

screen = clue.simple_text_display(title="Weather Station", text_scale=2,
                                  colors=((255, 80, 80), (80, 180, 255), (255, 255, 0), (80, 255, 120)))

while True:
    temp_c = clue.temperature
    temp_f = temp_c * 9 / 5 + 32
    screen[0].text = f"{temp_c:.1f}C / {temp_f:.0f}F"
    screen[1].text = f"Humid {clue.humidity:.0f}%"
    screen[2].text = f"{clue.pressure:.0f} hPa"
    screen[3].text = f"Alt {clue.altitude:.0f} m"
    screen.show()
    time.sleep(1)
🔬 Experiments
Breathe on the board: humidity shoots up! Carry it up the stairs: altitude should climb by about 3 m per floor. Hold it in your hand: temperature rises.
🌡️ Heads up
The board warms itself a little, so its temperature often reads a couple of degrees high. Compare with a real thermometer and subtract the difference: that's calibration again.
🏆 Challenge
Turn the NeoPixel blue when it's cold, green when comfy, and red when hot.
Mission 12

👏Clap Detector

+150 XP

The microphone can't record words here, but it measures how loud it is. clue.sound_level gives a number, and clue.loud_sound() is True when it's louder than a threshold.

Noise meter

import time
from adafruit_clue import clue

while True:
    level = clue.sound_level
    print((level,))          # the comma makes it a tuple, so the Plotter can graph it!
    time.sleep(0.05)

Clap-on light

import time
from adafruit_clue import clue

light_on = False

while True:
    if clue.loud_sound(sound_threshold=500):
        light_on = not light_on          # flip True ↔ False
        clue.white_leds = light_on
        time.sleep(0.5)                  # ignore the echo of the same clap

Too jumpy? Make sound_threshold bigger. Not hearing you? Make it smaller. Check the noise meter to pick a good number.

⚔️ Boss Level

⚡Reaction Race

+300 XP

Time to combine powers: screen + NeoPixel + buttons + speaker + time + random. Wait for green, then hit A as fast as you can. Press too early and you lose!

import time
import random
from adafruit_clue import clue

clue.pixel.brightness = 0.3
screen = clue.simple_text_display(title="REACTION RACE", text_scale=2)
best = None                      # None = "no score yet"

def show(line0, line1="", line2=""):
    screen[0].text = line0
    screen[1].text = line1
    screen[2].text = line2
    screen.show()

while True:
    best_text = "Best: --" if best is None else f"Best: {best} ms"
    show("Press A", "to start", best_text)
    while not clue.button_a:     # wait for A
        pass
    while clue.button_a:         # wait for A to be let go
        pass

    show("Get ready...", "wait for GREEN")
    clue.pixel.fill((255, 0, 0))
    wait = random.uniform(1.5, 4.0)
    start_wait = time.monotonic()
    cheated = False
    while time.monotonic() - start_wait < wait:
        if clue.button_a:        # pressed too early!
            cheated = True
            break

    if cheated:
        clue.pixel.fill((255, 0, 255))
        clue.play_tone(150, 0.6)
        show("TOO EARLY!", "Try again")
        time.sleep(2)
        continue                 # jump back to the top of the loop

    clue.pixel.fill((0, 255, 0))
    clue.play_tone(1000, 0.05)
    go = time.monotonic()
    while not clue.button_a:
        pass
    ms = int((time.monotonic() - go) * 1000)
    clue.pixel.fill((0, 0, 0))

    if best is None or ms < best:
        best = ms
        clue.play_tone(523, 0.1)
        clue.play_tone(784, 0.2)
        show(f"{ms} ms", "NEW RECORD!")
    else:
        show(f"{ms} ms", "Nice try!")
    time.sleep(2)
    while clue.button_a:
        pass

New things here: time.monotonic() is a stopwatch that counts seconds since the board started, break jumps out of a loop, continue skips to the next round, and None means "nothing yet".
